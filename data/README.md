# Data

The raw CSV files are not stored in this repository. To rebuild or refresh the report, place the following files in this folder:

| File | Description |
|---|---|
| `Customer Loyalty History.csv` | 16,737 members, one row each (profile, loyalty card, CLV, enrollment and cancellation dates) |
| `Customer Flight Activity.csv` | 392,936 monthly activity rows for 2017 and 2018 (flights, distance, points) |
| `Calendar.csv` | Daily calendar, 2012 to 2018 |
| `Airline Loyalty Data Dictionary.csv` | Field descriptions (documentation only) |

Field definitions are in the data dictionary. Confirm the source's terms of use before redistributing the raw files.
